A coherent lifecycle for AI-assisted development

Five Claude Code plugins. Specify, design, implement, review — each step produces an artifact, not conversation.

View on GitHub See the lifecycle

Why this exists

The problem

Each prompt starts from scratch. There's no shared context between planning and implementation — no spec, no design record, no review gate.

The solution

Each plugin handles one phase and produces a concrete artifact — a spec, an ADR, tested code, a findings report. Artifacts flow forward: specs feed implementation, implementations feed review.

The lifecycle

Four phases, connected by artifacts. Each plugin works standalone.

Five plugins, one suite

Each plugin works standalone. Together they form the full lifecycle.

plan

Triage, spec, and TDD plan generation. Accepts a task description, produces a structured spec with acceptance criteria and vertical slices.

Produces
SPEC-NNN-slug.md

arch

Design interview sessions. Walks through trade-offs, records decisions as ADRs, generates OpenAPI specs and database schemas.

Produces
ADR, OpenAPI YAML, DDL

impl

Takes a spec and executes it slice by slice. Enforces red-green-refactor at every step. Also handles debugging, refactoring, and commits.

Produces
Tested, committed code

review

Runs code quality, security, and accessibility checks in parallel. Produces a unified, deduplicated findings report.

Produces
review-report.md

skil

Workflow router. Routes tasks to the right plugin and lists available commands.

Entry point
/skil:help

What the output looks like

Excerpts from plugin runs against a real codebase.

Spec excerpt /plan:sdd 
## Acceptance Criteria

### Slice 1: Task Triage
GIVEN a plain-language task description
WHEN  the triage agent receives the input
THEN  it classifies the task as TRIVIAL | SMALL | FEATURE | EPIC
  AND  assigns a risk level of LOW | MODERATE | HIGH
  AND  routes to the appropriate workflow depth

### Slice 2: Context Gathering
GIVEN a triaged FEATURE-size task
WHEN  the context-gatherer agent runs
THEN  it identifies entry points, conventions, and hotspot files
  AND  produces a structured context summary for spec building

## Architecture Recommendation
# Pattern: Modular monolith with agent pipeline
# Each agent handles one workflow phase
# Artifacts flow forward via deterministic file paths

Abridged. Full specs include TDD plans, risk assessments, and file path inventories.

Review excerpt /review:review 
## What's Working
- Clean separation between triage, context, and spec agents
- Deterministic artifact paths prevent path drift across runs
- Model tier annotations match task complexity
